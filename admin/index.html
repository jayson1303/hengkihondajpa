Petunjuk Pengelolaan Data Dealer

Selamat datang di Dashboard Admin Hengki Honda JPA. Semua data yang Anda ubah di sini akan langsung terhubung ke database Google Firebase (Firestore & Storage) dan otomatis diperbarui di landing page dealer tanpa perlu edit kode HTML.

  • Kelola Motor & Kredit: Tambah varian warna motor, upload foto motor, atur harga OTR cash, dan atur tabel simulasi cicilan FIF & OTO.
  • Fitur Import: Anda dapat mengimpor file Excel PL Fif Updated.xlsx dan PL Oto Updated.xlsx atau menginisialisasi seluruh motor sekaligus dengan 1 klik!
  • Template WhatsApp: Sesuaikan format chat order yang masuk ke WhatsApp sales agar informasi motor, warna, OTR cash, leasing (FIF/OTO), DP, dan tenor langsung rapi terformat.
